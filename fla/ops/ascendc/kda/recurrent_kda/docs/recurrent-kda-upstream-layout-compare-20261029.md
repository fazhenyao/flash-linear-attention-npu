# 当前 UB State 排布优化版与远程主线性能对比

2026-10-29，在 A5_1 使用 msprof 对两版公开 recurrent_kda 入口重新计时。只测性能，本轮没有修改算子实现或受保护的方案文档。

## 版本与环境

远程基线锁定本轮开始时 flashserve/flash-linear-attention-npu 的 main：`8c4b3691e92c6ac3685742eebe3314618c9bf53b`。原已验证标准构建对应475个算子、公共组件、构建依赖及 Python 通路源文件的 Git blob 与该提交逐一一致，故复用冻结包 `rkda-kfirst-worst-pipeline-20261029/packages/upstream`。这不是历史“可接受实现”，也不是 UB 排布修改前的当前实现。

当前版为 `codex/recurrent-kda-x8-pr` 的 `d23fb9e8` 加已验证的方案对齐和 K-first 32B UB 行 padding 改动。与上轮验证的构建输入核对23个相关实现及 Python 通路文件，哈希全部一致；测试未改变源文件。完整构建、186例 CPU 精度、74项接口、9项确定性、4项内存检查沿用同一构建的 UB 行距优化记录，本轮不重复运行 ATK。

环境：A5_1，Ascend950PR 物理卡7/逻辑卡0，CANN 9.2.0-beta.2，Python 3.11.17、torch 2.9.0+cpu、torch_npu 2.9.0.post6。两版均为56个 block。服务器存在其他用户常驻进程，不宣称独占设备；设备状态原样保存。

## 用例与统计

issue680 全部36组形状：B=32/64/72，H=16，HV=32/48/128，T=1/2/4/8，K=V=128。各覆盖 V-first/K-first × FP32/BF16 State，共144组合。QKV/out 为 BF16，辅助输入 FP32；packed TND、fused QKV view、QK norm/raw gate/beta sigmoid 开启，原位并返回最终 State，无 indices。两版 manifest 的所有 shape/stride/dtype、参数、seed 完全一致。当前版 X 按请求最大长度选择1/2/4/8，没有强制全部取8。

每组合预热3次、正式采样5次，统计 msprof `Task Duration(us)` 的算术均值。按 Task Start Time 排序，仅筛选 `OP Type=RecurrentKda`、`AI_VECTOR_CORE`；每版1152条目标 kernel 记录，保留720条正式样本。CSV 各2304行、48列；其余行为输入准备等辅助算子，不纳入比较。结果是 kernel 耗时，不是含 metadata 同步的完整 Python 调用延迟。

首轮有少量明显尖峰与波动。按任一版5样本 CV>3% 选中11个组合，另加与先前同二进制验证结果不符的 K-first FP32 ID0/1，共13组合。两版均整组重新预热3次、采样5次，且反转版本顺序；最终使用全部5个重测样本，未删除单个样本。原始首轮和重测 CSV/JSON 均保留。

```bash
msprof --output="$root/$label-msprof" --task-time=on \
  python "$root/perf_cases.py" --package "$package" \
  --case-root "$old/source/tests/atk/recurrent_kda" \
  --warmup 3 --samples 5 --manifest "$root/$label-manifest.json"
```

## 汇总

耗时比=当前/远程；变化=(耗时比−1)×100%，负值表示当前更快。下表对36个逐例耗时比取几何均值。

| State 布局 | State 类型 | 耗时比几何均值 | 耗时变化 | 当前更快 | 逐例比值范围 |
| --- | --- | --- | --- | --- | --- |
| V-first | FP32 | 0.8594 | -14.06% | 35/36 | 0.6678–1.0055 |
| V-first | BF16 | 0.9629 | -3.71% | 20/36 | 0.7788–1.1150 |
| K-first | FP32 | 1.0066 | +0.66% | 18/36 | 0.6765–1.2892 |
| K-first | BF16 | 0.9873 | -1.27% | 18/36 | 0.7546–1.1739 |

当前版 V-first FP32 整体改善最明确，35/36例更快，唯一回退为 ID16 的0.55%。V-first BF16 整体降低3.71%，但16/36例回退，最差 ID7（T=8）增加11.50%。K-first FP32 整体增加0.66%，BF16整体降低1.27%，均只有18/36例更快，因此当前实现尚未在全部模型 case 上优于远程主线。

回退主要集中在长序列：T=8 的9组形状中，V-first FP32 耗时比几何均值0.8908，V-first BF16为1.1010，K-first FP32为1.2799，K-first BF16为1.1664。K-first FP32最差 ID3：673.051→867.679 μs（+28.92%）；K-first BF16最差 ID27：1063.558→1248.493 μs（+17.39%）。本轮仅计时，未重新采集这些回退的流水，不能把具体指令原因当作已证实结论。

最终使用组的最大样本 CV：远程1.42%，当前1.41%。首轮波动不能全部据此判定为外部任务干扰；也没有删去实际回退。
