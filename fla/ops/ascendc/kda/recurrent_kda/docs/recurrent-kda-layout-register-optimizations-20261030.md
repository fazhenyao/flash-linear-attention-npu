# RecurrentKda 分布局寄存器优化

2026-10-30，基于已验收reg20，按V-first点积融合、K-first BF16打包、K-first点积与访存调度的顺序分别实验。原始方案文档不修改，整tile完成后批量搬出out保持不变。

## 设计与判定

prediction与out的128列点积均先合并两个64列乘积，再归约64个lane。将 `a*b+c*d` 的两次乘法一次加法替换为一次乘法一次融合乘加，静态每行每点积少一条、每token共少256条Vector指令。归约树及输出lane组织不变，但FMA改变舍入，必须沿用原标杆与阈值验收。

K-first BF16成对写回时，仅需保留低半字的BF16位模式。将 `low=(low<<16)>>16` 替换为与 `0xFFFF` 按位AND，静态每token少128条位操作；常量准备、实际编译指令与寄存器开销另行核对。该项不改变BF16转换和舍入。

K-first读取、衰减和预测的交错调度单独实验，不与点积融合混合归因。FP32与BF16分别选择；单纯拆函数、改变R或缩短寄存器生命周期不直接视为指令数减少。

每项先标准构建安装与身份审计，再132例原有精度和54例对齐精度，最后用msprof Task Duration同卡比较。性能典型用例覆盖issue680 ID0/2/3/7/35×两布局×两State dtype，3预热+5正式样本。最终保留组合扩展到完整144组；动态指令通过正式kernel的小规模完整simulator诊断确认，不将仿真耗时当作模型性能。

## 精度、确定性与指令验证

layout22至layout26均完成标准单算子run构建安装、libcust_opapi一致性检查、72个kernel对象审计，并通过132例原有精度及54例对齐精度。CPU标杆、输入值域和混合容差未修改。最终layout26另外通过74项公开接口及9项确定性验证，每项确定性执行3次。A5_1精度初期使用卡3；layout25首例停滞后终止自有进程并保存失败记录，改用卡6完成layout25/26验证。未把中断轮次计为通过，也不认定其根因已经定位。

完整小规模simulator为正式包原生对象、单AIV、B=2/H=HV=1/T=8/K=V=128、X=8、BF16 State，两个任务共16 token，均到HOST_FINALIZED。V-first最终50200条trace指令事件，对照54280条；VMUL减4096、VADD减4096、VMULA增4096，Vector算术净减4096条，另增16条SMOV，总事件净减4080条。K-first BF16最终59585条，对照65725条；点积算术净减4096条、打包位操作净减2048条，另增4条常量准备事件，总事件净减6140条。归约次数VCADD=4128、必要SMEM_BAR=80不变。

对应仿真完整区间V-first为33.674→32.160μs，K-first BF16为59.959→56.941μs，仅用于诊断。K-first交错版相对融合点积版指令数不变，仿真56.553→56.941μs略慢，真机长用例约改善0.5%～0.8%；调度收益以真机计时判定，不声称交错减少指令。上述动态计数覆盖BF16 State，不冒充FP32 State的采集结果。

原生小用例逐位核对通过：打包AND前后out/State一致；K-first BF16交错前后、K-first FP32交错候选前后out/State一致；最终组合V-first与layout22、K-first BF16与layout25也逐位一致。FMA相对原始点积的数值变化按原CPU混合容差验收，不要求与reg20逐位一致。

本轮未改UB地址、数据类型、State bank生命周期、必要同步、预取及整tile完成后批量搬出out，未重复原生内存检测。改动仅在arch35；A2/A3未上板。仓库issue覆盖188项通过；全算子静态扫描仍有当轮114项host DFX-MESSAGE问题，两个本轮kernel头文件无静态发现，不能将全算子静态扫描写成通过。
