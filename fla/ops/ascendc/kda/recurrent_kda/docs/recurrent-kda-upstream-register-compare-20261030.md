# 当前寄存器优化版与远程 main 性能对比

2026-10-30，比较 recurrent_kda 当前实现与远程仓库最新 main 的设备 kernel 耗时。本轮不修改算子实现或受保护的方案文档，不运行 ATK 任务。

## 版本与环境

远程基线为本轮显式拉取的 `flashserve/flash-linear-attention-npu` 分支 `refs/heads/main`：`4cbcd01187c98afd0d8b187f06c3d4227f52de4c`，提交时间2026-10-30 09:17:21 +08:00，PR #1007。使用明确分支 ref，避免与同名 main tag 混淆。

该提交相对已验证标准构建 `8c4b3691e92c6ac3685742eebe3314618c9bf53b` 仅修改 `ci/tests/test_install_workflows_wheel_layout.py` 和 `scripts/check_install_workflows.py`；算子、公共组件、构建源码及 Python 通路未变。因此复用此前通过475文件源码核对的冻结包，本轮再次核对其72个 kernel 对象、libcust_opapi 和 stable 库 SHA256，全部一致。这不是历史“可接受实现”，也不是本轮 Stage16。

当前版为 `codex/recurrent-kda-x8-pr` 中已验证的 reg20：V-first与K-first BF16使用公共beta×k及MulAddDst，K-first FP32保留原乘加路径。18个算子实现及Python通路源文件与对应构建一致，仅有一处空白行的行末空格清理；全部包二进制身份另行校验。原186例精度、74项接口和9项确定性验收见[寄存器优化记录](recurrent-kda-a5-register-optimizations-20261030.md)，本轮不重复精度测试。

环境为A5_ci，Ascend950PR物理卡4/逻辑卡0，CANN 9.2.0-beta.2，Python 3.11.17，torch 2.9.0+cpu、torch_npu 2.9.0.post6。两版均56个block。机器存在其他进程，不声称独占设备；保留前后设备快照和每例计算前后的占用记录。每版先完成8组小规模正常运行及有限值检查，再采集完整模型用例。
